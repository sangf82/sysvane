## Added
- Displays page: control your monitors over DDC (brightness, contrast, colour, picture settings) with saved profiles and a quick switch between monitor colour and graphics card colour.
- Monitors show their real names (for example AL258Q), and two identical monitors are told apart. An Identify button dims the screen you are editing three times so you can see which one it is.
- Settings page with version, update check, language and theme.
- "Start with Windows" switch, and an alert that offers to restart the core with administrator rights when it needs them.
- Process icons in the Processes list.

## Changed
- Redesigned Overview and Processes pages.
- Language and theme moved to Settings as dropdowns; core errors show as a small chip in the corner.

## Fixed
- Removed an empty "Background program" section from Settings.
- Dropdown labels start with a capital letter.

## Safety
- This release writes to monitors over DDC. Only an allowlist of image settings can be written; factory reset, power-off, standby and input-source commands are never sent.
